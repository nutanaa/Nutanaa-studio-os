1. Everything is modular.

2. Everything is plugin based.

3. Every AI provider is replaceable.

4. Every agent is replaceable.

5. Every workflow is configurable.

6. Every feature must have tests.

7. Every feature requires documentation.

8. No business logic inside the UI.

9. Every module has a public interface.

10. Communication between modules uses contracts.

11. Every action is logged.

12. Every AI output is reviewable.

13. Human approval can be inserted at any workflow stage.

14. Providers must support fallback and retry.

15. Character consistency is treated as project state.

16. Assets are never overwritten; version them instead.

17. Every configuration is externalized.

18. Components should be independently deployable.

19. Repository structure changes require architectural approval.

20. Long-term maintainability is more important than short-term speed.
